# BrowserWall

`BrowserWall` is a collection of web browser based apps for desktop customization renderers, allowing users to create wallpapers, widgets, and more based on html, css, and javascript. Most, if not all, at meant to be be run locally.

## The Collection

### modified wv2wall

see [modified-wv2wall](https://github.com/EliteDiamonHawk/wv2wall)

- forked wv2wall from `Superswan`(see credits) with minor feature additions.
- best used if you use webview2 based web browser as it will share webview2 resources

### chromiumwall

see [chromiumwall](https://github.com/EliteDiamonHawk/chromiumwall)

- expanded version of wv2wall to support all chromium based browsers
- set to your default browser so that the wallpaper can share resources with it.
- no integration with the webbrowser so less control. 

### ultralightwall

see [ultralightwall](https://github.com/EliteDiamonHawk/ultralightwall)

- version that uses the ultralight framework instead of the resouce heavy web browsers such as wv2 and chromium.

### ultralightwidgets

see [ultralightwidgets](https://github.com/EliteDiamonHawk/ultralightwidgets)

- ultralightwall modified to widgets only, covering only parts of the screen instead of the whole screen, therefore saving resources further.
