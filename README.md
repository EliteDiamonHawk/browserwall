# BrowserWall

`BrowserWall` is a collection of web browser based apps for desktop customization renderers, allowing users to create wallpapers based on html, css, and javascript. Meant to be be run locally.

## The Collection

### ultralightui-shell

see [ultralightui-shell]([https://github.com/EliteDiamonHawk/ultralightwall](https://github.com/EliteDiamonHawk/ultralightui-shell))

- Uses the ultralight framework instead of the resouce heavy web browsers such as wv2 and chromium.
- also contains support for widgets, a start menu, and perhaps more.

### modified wv2wall

see [modified-wv2wall](https://github.com/EliteDiamonHawk/wv2wall)

- forked wv2wall from `Superswan`(see credits) with minor feature additions.
- best used if you use webview2 based web browser, such as Edge, as it will share webview2 resources.

### chromiumwall

see [chromiumwall](https://github.com/EliteDiamonHawk/chromiumwall)

- expanded version of wv2wall to support all chromium based browsers
- set to your default browser so that the wallpaper can share resources with it.
- no integration with the webbrowser so less control.
